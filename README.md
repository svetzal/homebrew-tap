# Homebrew Tap

Custom Homebrew formulas by svetzal.

## Installation

```bash
brew tap svetzal/tap
```

## Available Formulas

### microgentic

An adaptive coding agent optimized for small models, with a streamed terminal
conversation and isolated benchmark mode.

```bash
brew install svetzal/tap/microgentic
microgentic setup --apply
microgentic
```

See [Microgentic](https://github.com/svetzal/microgentic) for provider setup and
shell workflows. `mg` remains an optional user-defined alias.

### epilogue-tracker

User-centric work management CLI using the Screenplay Pattern.

```bash
brew install svetzal/tap/epilogue-tracker
```

Or after tapping:

```bash
brew install epilogue-tracker
```

## Updating

```bash
brew update
brew upgrade epilogue-tracker
```
